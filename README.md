# Smart Civic Waste Routing — Mysuru (Exact Clone)

An exact, high-fidelity replica of the **Smart Civic Waste Routing — Mysuru** web application (originally from `https://hello-web-magic-70.lovable.app`) featuring the magnificent **Mysore Palace (Amba Vilas Palace)** as the primary hero landmark photo.

---

## 🌟 What's Included

1. **Exact 1:1 Visual Clone**:
   - Same typography (Archivo, DM Sans, IBM Plex Mono)
   - Same design tokens, color palette, gradients, glassmorphism badges, and layout structure
   - Fully responsive design matching desktop and mobile viewports

2. **Upgraded Hero Image**:
   - Features a high-resolution, grand daytime architectural photo of the **Mysore Palace (Amba Vilas Palace)** with lush royal gardens and wide walkways.
   - Built-in live photo switcher toggle allowing you to switch between the iconic **Mysuru Palace view** and the **Sanitation Crew view**.

3. **Interactive Enhancements**:
   - **Report Waste Modal**: Click "Report waste" to open an interactive complaint submission dialog with automatic PIN-to-MCC-Ward jurisdiction resolution.
   - **Live Complaint Tracking**: Search for complaints (e.g. `MYW-2026-0418`) or track newly submitted complaints in real-time.
   - **Live Routing Engine Demo**: Step-by-step visual routing pipeline (Citizen -> Locate -> Route -> Assign -> Resolve).
